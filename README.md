# المعتق للعود — موقع المزاد والجملة والقطاعي

موقع ثابت يعمل على **GitHub Pages**، ومربوط بـ **Firebase** (تسجيل الدخول + قاعدة بيانات Firestore لحظية).
قبل إضافة إعدادات Firebase يعمل الموقع في **وضع العرض** ببيانات تجريبية، فتقدر تشوفه وتجرّبه فوراً.

## الصفحات
| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `auction.html` | قاعة المزاد المباشر (مزايدة لحظية، رقم مزايدة لكل عميل، تمديد آخر 30 ثانية) |
| `wholesale.html` | الجملة: جدول الأسعار + طلب عرض سعر |
| `retail.html` | متجر القطاعي + السلة وإرسال الطلب |
| `terms.html` | شروط المزاد والشحن (مسودة تُعدّل) |
| `admin.html` | لوحة التحكم (للمدير فقط) |

## خطوات الإطلاق

### 1) GitHub
1. أنشئ مستودعاً جديداً (مثلاً `almuataq`).
2. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع (كل الملفات في مكان واحد بدون مجلدات).
3. Settings › Pages › Source: `Deploy from a branch` › Branch: `main` / `(root)` › Save.

### 2) Firebase
1. من console.firebase.google.com أنشئ مشروعاً جديداً.
2. **Authentication** › Get started › فعّل **Email/Password**.
   ثم Settings › Authorized domains › أضف `اسمك.github.io`.
3. **Firestore Database** › Create database › Production mode.
4. **Rules**: انسخ محتوى `firestore.rules` والصقه، وغيّر `admin@example.com` إلى بريدك، ثم Publish.
5. Project settings › Your apps › أضف تطبيق Web › انسخ قيم `firebaseConfig`.

### 3) الإعدادات
افتح `firebase-config.js`:
- الصق قيم `firebaseConfig`.
- ضع بريدك في `ADMIN_EMAILS` (نفس البريد الموجود في القواعد).
- عدّل `CONTACT` (الواتساب، البريد، السجل التجاري).

### 4) أول دخول للمدير
1. افتح الموقع › دخول / تسجيل › «حساب جديد» بنفس بريد المدير.
2. يظهر زر **لوحة التحكم** في الأعلى.
3. أضف: بيانات المزاد ← القطع ← منتجات القطاعي ← أسعار الجملة.

## تشغيل المزاد
1. في لوحة التحكم › المزاد: احفظ اسم المزاد وموعده ومدة كل قطعة.
2. أضف القطع (رقم، اسم، سعر افتتاح، المنشأ، الوزن، الصورة).
3. وقت المزاد: اضغط **«اعرضها الآن»** على القطعة، فتظهر لكل الحضور وتبدأ المزايدة.
4. عند انتهاء الوقت: **«إنهاء وترسية»** (تُسجّل للرقم الأعلى)، ثم اعرض القطعة التالية.
5. تقدر تمدّد الوقت دقيقتين من زر «+2 دقيقة».

## الصور
ضع صور المنتجات والقطع في المستودع نفسه واكتب مسارها في لوحة التحكم، مثل: `oud-1.jpg`.

## ملاحظات

- قاعدة البيانات مجانية ضمن حدود خطة Spark في Firebase.
